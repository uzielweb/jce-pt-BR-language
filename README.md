# JCE Editor - Pacote de Idioma Português do Brasil (pt-BR) 🇧🇷

Pacote de tradução 100% completo, atualizado e validado para o **JCE Editor** no **Joomla! 4.x, 5.x e 6.x**.

---

## 📦 O que está incluído neste pacote:

1. **Painel de Controle e Administração (`administrator/language/pt-BR/`)**:
   - Todas as opções da **Configuração Global do Editor** (Validação HTML, Sanitização DOMPurify, Doctype, Codificação de Entidades, Espaços não separáveis, Contêineres, Estilos do Editor, etc.).
   - Gerenciador de **Perfis do Editor** (Parâmetros, Layouts e Atribuição de Usuários/Grupos).
   - Gerenciador de Arquivos e Mídia.
   - Todos os 7 plugins administrativos (`plg_content_jce`, `plg_editors_jce`, `plg_extension_jce`, `plg_fields_mediajce`, `plg_installer_jce`, `plg_quickicon_jce`, `plg_system_jce`).

2. **Frontend & Editor TinyMCE (`language/pt-BR/`)**:
   - Todas as 47 ferramentas e diálogos pop-up do editor (Tabelas, Links, Âncoras, Mídia, Código-fonte, Imagens, Caracteres Visuais, Salvamento Automático, etc.).

3. **API (`api/language/pt-BR/`)**:
   - Suporte completo para chamadas e endpoints via Web Services/API.

---

## 🚀 Como Instalar

### Opção 1: Instalação via Painel do Joomla (Recomendado)
1. Baixe o arquivo `.zip` da versão mais recente na seção [Releases](https://github.com/uzielweb/jce-pt-BR-language/releases).
2. No painel de administração do Joomla, acesse: **Sistema > Instalar > Extensões**.
3. Arraste e solte o arquivo `.zip` para instalar.

### Opção 2: Instalação via JCE Control Panel
1. Acesse **Componentes > Editor JCE > Painel de Controle**.
2. Clique em **Opções / Instalar Complementos** e carregue o arquivo `.zip`.
